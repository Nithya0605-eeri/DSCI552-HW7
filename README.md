DSCI 552 — Homework 7

Course: Machine Learning for Data Science
University: University of Southern California

Overview

This assignment covers:

* Multi-class and multi-label classification using Gaussian and L1-penalized SVMs.
* Class imbalance handling using SMOTE.
* K-Means clustering with 50 Monte Carlo simulations.
* Hierarchical clustering using complete and single linkage.

Dataset

Anuran Calls (MFCCs) — UCI Machine Learning Repository.

Project Structure

* data/ — Dataset files
* notebook/ — Jupyter Notebook with code and results
* requirements.txt — Required Python libraries

How to Run

1. Install dependencies: pip install -r requirements.txt
2. Open the notebook in local Jupyter.
3. Run all cells sequentially.
